Smart Parking Allocation System

A Python-based academic project for intelligent parking slot allocation using constraint validation, utility-based decision support, and a structured output pipeline.

View GitHub Repository Read README Explore Project

Project Overview

The Smart Parking Allocation System (SPAS) assigns vehicles to suitable parking slots by checking parking constraints and ranking valid options using a utility score. The project models vehicles and slots, filters invalid assignments, selects the best feasible slot, and generates structured outputs for academic evaluation.

Project Objectives

  • Model the smart parking problem using structured Python-based representation.
  • Apply parking constraints to validate feasible slot assignments.
  • Use utility-based scoring to improve allocation quality.
  • Generate structured outputs for analysis, comparison, and viva explanation.
  • Build a neat integrated Python pipeline for academic submission.

Core Features

  • Vehicle and parking slot modeling
  • Constraint-based slot validation
  • Utility-based slot scoring
  • Multiple academic test case execution
  • Structured text, CSV, and chart generation
  • Clean modular Python implementation

Academic CO Coverage

CO / Module Academic expectation Current SPAS coverage
CO1 / Problem Formulation Represent entities, rules, constraints, and goal clearly. Implemented through vehicles, parking slots, rule definitions, and structured parking allocation modeling.
CO2 / Search Reasoning Demonstrate systematic algorithmic exploration and comparison. Partially demonstrated through structured allocation flow and case-based evaluation; can be extended further with explicit search metrics.
CO3 / CSP Allocation Apply constraints, valid domains, and rule-based filtering. Implemented through parking constraints such as size fit, reservation rules, EV charging support, and slot availability.
CO4 / Decision Making Select the best valid outcome using utility or scoring logic. Implemented through utility-based slot scoring using priority, distance, reserved-slot preference, and charging compatibility.
CO5 / Uncertainty Reasoning Handle uncertain or dynamic conditions in decision support. Currently reflected as an extension-ready area for dynamic slot availability and uncertainty-aware allocation.
CO6 / Integrated AI Pipeline Combine all modules into one explainable system with outputs. Implemented through the final Python pipeline with result files, summaries, and charts for academic review.

System Workflow

1

Define vehicles with type, size, priority, VIP status, and EV requirements.

2

Define parking slots with size, distance, reservation, charger, and availability properties.

3

Apply parking constraints to eliminate invalid slot assignments.

4

Evaluate feasible slots using utility-based scoring logic.

5

Select the best valid assignment and generate structured final outputs.

Why This Project Matters

Smart parking is a practical real-world engineering problem where efficient allocation can reduce congestion, improve parking utilization, and support intelligent transport systems. This project demonstrates how AI-inspired reasoning can be applied to a relatable parking scenario using modular Python implementation and explainable decision flow.
