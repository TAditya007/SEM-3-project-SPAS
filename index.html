Smart Parking Allocation System

A Python-based academic project that allocates vehicles to suitable parking slots using constraint-based reasoning, utility-based decision making, and structured AI pipeline design.

View GitHub Repository Read README Explore Project

Project Overview

The Smart Parking Allocation System (SPAS) is designed to assign vehicles to the most suitable parking slots by checking constraints and evaluating utility scores. The system models vehicles and parking slots, filters invalid assignments, ranks feasible options, and selects the best slot in a structured, explainable, and academically meaningful way.

Project Objectives

  • Model a smart parking problem using AI-oriented problem representation.
  • Apply constraint-based validation to ensure correct slot assignments.
  • Use utility-based scoring to select the best available parking slot.
  • Generate structured outputs for analysis, comparison, and explanation.
  • Build a clean integrated pipeline suitable for academic demonstration.

Core Features

  • Vehicle and parking slot modeling
  • Constraint-based slot validation
  • Utility-based slot scoring
  • Multiple test case execution
  • Structured text, CSV, and output generation
  • Clean modular Python implementation

Academic CO / Module Coverage

Module / CO Area Academic Requirement SPAS Implementation Coverage
Module 1: Problem Formulation Represent the problem, states, actions, constraints, and goal. Vehicles, slots, constraints, and allocation objective are modeled clearly.
Module 2: Search / Algorithmic Reasoning Use structured algorithmic reasoning to evaluate possible solutions. The allocation flow evaluates feasible options systematically and supports case-wise analysis.
Module 3: CSP Allocation Apply constraints, valid domains, and rule-based filtering. Slot assignment is validated using constraints such as compatibility, size, and parking conditions.
Module 4: Decision Making Select the best outcome using utility or scoring logic. Utility-based scoring ranks valid slots and chooses the best final allocation.
Module 5: Reasoning Under Uncertainty Consider dynamic or uncertain scenarios in decision logic. The project architecture supports extension toward uncertain parking scenarios and adaptive logic.
Module 6: Integrated AI Pipeline Combine all modules into one complete working system. The final pipeline integrates modeling, validation, scoring, testing, and output generation.

System Workflow

1

Define vehicles with type, size, priority, and parking requirements.

2

Define parking slots with supported properties and constraints.

3

Apply constraints to eliminate invalid parking allocations.

4

Evaluate feasible slots using utility-based scoring logic.

5

Select the best slot and generate final structured outputs.
