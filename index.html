Smart Parking Allocation System

A Python-based project that allocates vehicles to suitable parking slots using constraint-based reasoning and utility-based decision making.

View GitHub Repository Explore Project

Project Overview

The Smart Parking Allocation System (SPAS) is designed to assign vehicles to the most suitable parking slots by checking constraints and evaluating utility scores. The system models vehicles and slots, filters invalid assignments, scores valid options, and selects the best available slot in a structured and explainable way.

Core Features

  • Vehicle and parking slot modeling
  • Constraint-based slot validation
  • Utility-based slot scoring
  • Multiple test case execution
  • Structured text, CSV, and output generation

Technologies Used

  • Python
  • Object-Oriented Programming
  • Constraint Satisfaction concepts
  • Utility-based decision logic
  • GitHub and GitHub Pages

System Workflow

1

Define vehicles with type, size, and parking requirements.

2

Define parking slots and their supported conditions.

3

Apply constraints to remove invalid allocations.

4

Score valid slots using utility-based evaluation.

5

Select the best slot and save the final results.

Academic Objective

This project demonstrates how intelligent allocation can be implemented using structured constraints, decision logic, and optimization-oriented scoring. It is presented as an academic implementation of smart parking management using Python.
